# TANDAZO TV

TANDAZO TV es una aplicación personal para Android TV 11 que ofrece una pantalla de inicio moderna y personalizable, inspirada en las interfaces de consolas.

El proyecto integra información de películas y series mediante la API de TMDB para mostrar recomendaciones, tendencias e imágenes cinematográficas.

Actualmente se encuentra en desarrollo para uso personal y no comercial.
